# System-Modeling-with-ANN
This repository presents a neural network-based system identification approach developed as part of a Master's thesis in Control Engineering. Using real input/output data collected from a servo-hydraulic motor and an approximate transfer function of the system, the MATLAB code trains Artificial Neural Networks (ANNs) to obtain a more accurate representation of the plant dynamics. The repository includes experimental datasets and configurable training options, making it useful for students, researchers, and engineers interested in control systems, system identification, and machine learning applications in engineering.
You can use the uploaded video to see how the code can be used.
